# 词典收敛记录

这份文档解释**词典为什么长成现在这样**。`anima_prompt.py` 里的 `TAG_MAP` 是三轮修正后的结果，这里留下每一轮的依据和取舍。

背景见 README 的「tag 是校验过的」一节：Anima 的 tag 表是筛选过的，按常识写会踩坑。

## 起点：按常识写的第一版

第一版词典 340 条，全部按「Danbooru 常见写法」凭直觉填写。拿去和 Anima 官方表（24655 条）比对：

```
词典条目总数：340
不在 tag 表里的：44
```

**13% 的 tag 是模型不认识的死词。** 这些词写进 prompt 不会报错，只会静默失效——最难发现的一类错误。

### 表内没有对应词，删除（25 条）

删掉是**刻意的**：这些概念在 Anima 表里没有 tag，硬塞一个近义词等于编造。

**光影类**：顶光、底光、强光、柔光、高光、打光
—— 表里只有 `backlighting` / `sidelighting` / `underlighting` / `dim_lighting` 这类具体方向的光，没有通用的「柔光」「强光」。

**氛围类**：安静、温馨、神秘、梦幻、忧郁、浪漫、紧张、平静、热闹、可爱、帅气、优雅、恐怖、史诗感
—— **整个氛围词类别在 Anima 表里都不存在**。这类描述应该走自然语言，不该硬凑 tag。

**动作 / 场景类**：手放膝盖、屈膝、苦笑、酒吧、凌乱、正面视角
—— 表内无对应或语义不等价。

## 方法上的可复用处

如果你要扩词典，这套流程可以直接沿用：

1. 凭直觉写中文 → 英文 tag 映射
2. `check_tags.py` 找出表外条目
3. `suggest_fixes.py` 反查候选（按 post_count 降序，优先高频）
4. 有合适同义词就换，没有就删 —— **不要为了凑数塞近义词**
5. 重复到 0 条表外

**核心判断**：Anima 词表是筛选过的，与完整 Danbooru（33 万条）差异很大。不要相信记忆里的「常见 tag」，要相信表。
